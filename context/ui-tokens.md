# UI Tokens

## 1. Design Direction

The portfolio uses a:

- Minimal
- Clean
- Modern
- Professional
- Typography-focused
- Spacious

visual style based on the provided design reference.

---

## 2. Color Tokens

### Background

- Primary: `#FFFFFF`
- Secondary: `#F8F8F8`

### Text

- Primary: `#111111`
- Secondary: `#666666`
- Muted: `#999999`

### Borders

- Default: `#E5E5E5`
- Strong: `#D4D4D4`

### Accent

Use accent colors sparingly.

The primary visual language should remain mostly monochrome.

---

## 3. Typography

### Font Family

Use a modern sans-serif font.

Preferred:

**Inter**

### Weights

- Regular: `400`
- Medium: `500`
- Semibold: `600`
- Bold: `700`

### Hierarchy

- Hero heading: Large
- Page heading: Large
- Section heading: Medium/Large
- Card heading: Medium
- Body: Regular
- Metadata: Small
- Tags: Small/Medium

Typography should create hierarchy without excessive font sizes.

5. Layout
Container

Use a centered responsive container.

Suggested maximum width:

1200px

The container should have responsive horizontal padding.

6. Border Radius

Use restrained rounded corners.

Small: 8px
Medium: 12px
Large: 16px
Pill: 999px

Use pill radius for:

Tags
Badges
Small controls
7. Borders

Default border:

1px solid #E5E5E5

Use borders subtly.

Avoid heavy outlines.

8. Shadows

Use subtle shadows only where useful.

Preferred levels:

None
Small
Medium

Cards should generally rely more on borders and whitespace than heavy shadows.

9. Buttons
Primary Button
Dark background
White text
Medium weight
Rounded corners
Comfortable horizontal padding
Secondary Button
Transparent/light background
Dark text
Subtle border
Button States

Support:

Default
Hover
Focus
Active
Disabled
Loading
10. Cards

Cards should use:

White or near-white background
Subtle border
Medium/large radius
Consistent padding
Optional subtle shadow

Cards should remain visually lightweight.

11. Technology Tags

Technology tags should:

Use pill-shaped borders/radius
Use small readable text
Have subtle backgrounds
Maintain consistent spacing

Example:

Next.js
TypeScript
Gemini API
MongoDB
12. Responsive Breakpoints

Use standard responsive breakpoints.

Mobile: < 640px
Tablet: 640px – 1023px
Desktop: 1024px+
Large Desktop: 1280px+

Do not design mobile as a scaled-down desktop.

13. Section Spacing

Major sections should have generous vertical spacing.

Suggested range:

64px – 128px

Spacing should be reduced appropriately on smaller screens.

14. Hero

The hero should have:

Strong visual hierarchy
Large heading
Short supporting text
Clear CTA
Generous whitespace

Avoid unnecessary decorative elements.

15. Navigation

Desktop navigation should have:

Clear spacing
Simple typography
Minimal visual noise
Strong active/hover states

Mobile navigation should use a compact menu.

16. Project Grid

Desktop:

3-column or 2-column

Tablet:

2-column

Mobile:

1-column

The final column count should depend on the content and available width.

17. Images

Project images should:

Maintain consistent aspect ratios
Use rounded corners
Avoid distortion
Be optimized
Have appropriate alt text

Prefer actual project screenshots.

18. Icons

Use icons consistently.

Icons should:

Have consistent sizing
Align with text
Avoid excessive decoration
Have accessible labels when they represent actions
19. Animation

Animations should be subtle.

Use:

Opacity transitions
Small translations
Hover transitions
Button transitions

Avoid excessive motion.

Respect:

prefers-reduced-motion
20. Accessibility

All UI tokens must support:

Sufficient contrast
Visible focus states
Readable text sizes
Clear interactive states
Keyboard navigation

Do not rely on color alone.

21. Design Rule

The visual system should prioritize:

Whitespace
    >
Typography
    >
Hierarchy
    >
Subtle borders
    >
Subtle shadows
    >
Decorative effects

Keep the interface minimal and professional.
